rbxyoinker Roblox asset downloader

Runs locally. Credentials are stored in Windows Credential Manager and never leave this machine.

Paste an id or any catalog / library / create URL.

Recent

Usage

  • Enter an asset id or paste any Roblox URL, then Fetch to preview it.
  • Download walks the authorization ladder: Open Cloud key, then each saved account directly, then the creator's own places as a place-id context.
  • Bulk takes up to 1000 ids at once, or import a place / model file to pull every asset id out of it.
  • Leave Version empty for the latest, or enter a number to grab an older version.
  • Files save to your download folder (set in Settings); every download is kept in History.
  • Decals and images that resolve to an XML descriptor are followed once to the real image.

Before you start

  • rbxyoinker is a fan-made tool. It isn't made by, affiliated with or endorsed by Roblox.
  • Only download or reuse assets you made or have permission to use. Respect other creators and the Roblox Terms of Use.
  • A .ROBLOSECURITY cookie is a full login to that account. It stays on this PC in Windows Credential Manager. Never share it or paste it anywhere you don't trust.
  • Using your accounts with third party tools is at your own risk. The software comes as is, with no warranty (MIT license).
